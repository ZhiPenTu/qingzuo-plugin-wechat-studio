# 公众号 AI 工作台 v0.1.11

本次更新优化排版阶段的手机预览，让长文、配图和窄窗口下的检查更接近真实手机阅读效果。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 手机预览改为接近真机的 `390 × 844` 长宽比，替换原先偏矮的固定尺寸。
- 补充手机外框、圆角和阴影，预览内容增加移动端内边距，减少贴边和裁切。
- 预览中的图片自动限制在容器宽度内，长链接可以安全换行，不再撑破版面。
- 编辑区空间不足时自动切换为上下堆叠，窄窗口不再强行并排。
- 仅在窗口高度充足时启用吸顶预览，避免较矮窗口下预览被截断。
