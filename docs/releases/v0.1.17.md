# 公众号 AI 工作台 v0.1.17

本次更新重做文章项目页的信息组织与排版工作区布局，让篇目信息、正文编辑与手机预览各自占据清晰的位置。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 篇目信息集中在顶部步骤区：元数据、文件状态与上一步/下一步不再占用右侧常驻栏，正文获得更宽的编辑区。
- 元数据按「标题 + 作者」「摘要」「保存」分组，摘要说明与保存操作各自对齐；折叠信息面板不会丢弃尚未保存的输入。
- 文件状态改为对齐的两列清单，保留已保存/待生成的逐项标记与总数摘要。
- 排版页将主题、配色收为紧凑工具条，主题说明独立成块；正文区标注为「正文编辑 / article.md」。
- 手机预览保持 390:844 真实比例并维持可读字号，窄屏按比例缩放，长文在手机内滚动查看。
- 新增「放大预览」弹窗，以原始尺寸查看手机排版；关闭后焦点回到入口按钮。
- 压缩页头与步骤条高度，让排版内容更早进入首屏；窄屏自动纵向堆叠，长标题与长路径不再撑出横向滚动。
- 终审中「编辑标题/作者/摘要」会自动展开篇目信息并聚焦对应字段。
