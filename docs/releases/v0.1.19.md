# 公众号 AI 工作台 v0.1.19

本次更新把贴图工作流的提交目的地改为微信原生图片消息（`newspic`），不再把整组贴图拼成普通公众号文章。插件标识 `official.wechat-studio`，基于轻作插件 API 1.12.0，需要轻作 `v0.8.1`。

## 变更

- 贴图创建草稿和提交发布时使用 `article_type: newspic`，整组图片按原顺序写入 `image_info.image_list`。
- 每张贴图上传为永久素材并作为图片消息内容，首张同时作为封面；不再上传 HTML 正文，也不设置 `thumb_media_id`。
- 图片消息标题按微信限制收紧到 32 字，原摘要改为图片消息的说明文字。
- 草稿回执增加图片消息投递标记；升级前创建的普通图文草稿不会被误认成当前图片消息草稿。
- 本地 `drafts/` 文章项目继续保留，供预览、编辑和归档；微信提交只读取其中的图片资产。

## 验证

- `npm test`
- `npm run typecheck`
- `npm run build`
- `npm run validate`
- 轻作平台 `tests/platform/wechat.test.mjs` 覆盖图片消息请求体、图片顺序、永久素材上传与非法输入。
