# 公众号 AI 工作台 v0.1.5

配图结果预览版本，插件标识 `official.wechat-studio`，基于轻作插件 API 1.9.0。

## 新增

- 配图页生成完成后展示封面与正文图片缩略图。
- 点击任意缩略图可查看大图，便于逐张检查画面与信息位内容。
- 重新打开项目时，从已保存的 `img-plan.json` 和 `article.yaml` 恢复图片预览。
- 使用自有封面或正文图片时，也会同步更新预览列表。
