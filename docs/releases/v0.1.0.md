# 公众号 AI 工作台 v0.1.0

首个版本，插件标识 `official.wechat-studio`，基于轻作插件 API 1.9.0。

## 功能

- 完整创作流水线：选题、调研、写稿、内容审、排版、配图、终审、草稿与发布。
- 改写文章、新写文章、粘贴正文、公众号链接读取和继续本地草稿。
- 五步配置中心，支持对标文章提炼、结构推导、8 套主题、3 套配色和 9 个版式组件。
- 业务素材库：产品介绍、图片、同名说明和可选 AI 图片说明。
- 贴图工作流：1–9 张统一风格、方案确认、逐图配文、部分失败重试与导出。
- `.aws` 预设包预览、配置差异、预设替换、写作规范覆盖和白名单导出。
- 远程 MCP 只读搜索/网页读取工具选择，以及公众号草稿、发布和状态查询。

## 安全

- 工作区路径隔离、敏感文件拒绝、符号链接拒绝、原子写入和并发写入串行化。
- 微信封面与正文图片只接受当前文章目录下的 PNG/JPEG，宿主负责上传与地址替换。
- 发布前宿主原生确认；显式接口拒绝记为失败，网络中断或未知结果禁止自动重发。
- `.aws` 导出剔除模型配置、API Key、AppID、AppSecret、Token 和端点。

## 限制

- 不包含官网微信扫码登录、云端账号、积分计费或云端历史。
- 不支持 stdio MCP、第三方微信代理或微信原生图片消息自动发布。
- 公众号直接发布受账号认证、IP 白名单和接口权限约束。
