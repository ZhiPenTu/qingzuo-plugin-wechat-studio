# 公众号 AI 工作台 v0.1.16

本次更新重做贴图工作流的方案阶段：先生成整组方案，再按逐图方案小结生图，修复每张贴图观点、画面提示词和配文重复的问题。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 新增整组贴图方案：贴图类型、叙事线、整组主旨，以及每张独立的方案小结。
- 生成图片时会把整组叙事、主旨和当前这张的方案小结一起传给模型，不再只套统一模板。
- 强制校验方案小结、画面提示词和配文不重复；AI 方案失败时不再回退到相同的占位内容。
- 新增 `imgs/outline.md`，按贴图技能模板保存图序、画面描述、配文和 Prompt 要点。
- 修改方案、画面提示词、风格、媒介或主题语言后，相关旧图会标记为“需重生成”，不能继续创建草稿或发布。
- 单张生成、批量生成、保存文章项目和公众号草稿/发布均增加方案与图片状态门禁。
- 兼容旧版贴图会话；缺少新增方案字段时会提示补齐，不会误用旧图发布。
