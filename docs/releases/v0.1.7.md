# 公众号 AI 工作台 v0.1.7

配置中心新增可选 MCP 生图方式，插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 「视觉呈现」新增生图方式，可在共享 AI 图片模型和 MCP 生图工具之间切换。
- 可选择 MCP 服务与具体工具，并编辑包含 `{{prompt}}`、`{{size}}`、`{{count}}` 占位符的 JSON 参数模板。
- 封面、正文配图和整组贴图均支持 MCP 生图，兼容 base64、data URL、Anthropic source、MCP resource blob、structuredContent 和 GIF。
- 首次调用工具时由轻作逐项授权；会执行操作或产生费用的工具会明确提示，不再把 `readOnlyHint` 当作安全保证。
- 支持停止等待并保留已生成图片；结果未知时不会自动重发，任务 ID 写入批次目录的 `mcp-generation.json`。
- `.aws` 导出会递归清理 MCP 参数中的令牌与凭据字段。

## 验证

- `npm run validate`
