# 公众号 AI 工作台 v0.1.15

本次更新完善贴图工作流，从统一主题语言、单张生成与重做，到草稿归档、公众号草稿和发布形成完整闭环。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 贴图工作流支持统一设定主题语言和统一风格，生成方案与每张图片提示词保持一致。
- 每张贴图支持单独生成、重新生成、调整顺序和删除，不再默认重发整批。
- 支持将贴图方案保存为 `drafts/` 下的文章项目，并保留配文、图片和会话状态。
- 支持从文章项目创建公众号草稿、提交发布并查询发布状态。
- 草稿回执和贴图会话支持恢复；失败或未知状态可在确认后安全重置。
- 文章项目列表与详情支持删除；项目先移入所在 `drafts/` 子目录下的 `.trash/`，清理失败时保留回收路径供手动处理，不会恢复成残缺项目。
- 图片统一输出 JPEG 并限制在微信 1MB 以内；封面作为正文首张图片参与排版。
- 贴图卡片采用更紧凑的响应式布局，窄屏下编辑与预览更易操作。
