# 公众号 AI 工作台 v0.1.9

本次更新让配图失败后的重做更可控，并把缩略图、状态和操作入口收进对应图位卡片。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 每张封面和正文图都可以单独生成或重新生成，只提交当前图位的提示词，不再默认重发整批。
- 单张成功后合并生成映射并保留其他已成功图片；旧图位按 `slotIndex + alt` 迁移，文章增删图位后不会错绑图片。
- 区分生成失败、结果未知、中断和保存失败；结果未知不自动重发，保存失败时保留已生成的源图。
- 单张成功后会关闭旧批次的“重试失败项”入口，避免宿主重复提交已成功图片并产生额外费用。
- 配图卡片内展示缩略图、状态和生成按钮，用户自带图片模式也可以直接预览；屏幕较窄时更早切换为单列布局。
