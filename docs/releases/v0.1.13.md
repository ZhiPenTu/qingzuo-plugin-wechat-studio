# 公众号 AI 工作台 v0.1.13

本次更新让配图提示词真正基于文章内容生成，封面和正文图位都会引用标题、导语、章节结构与相邻原文，减少通用化描述和图文脱节。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 封面提示词绑定完整标题、文章主旨、章节线索和关键事实。
- 正文图位结合所在章节、图位说明、相邻原文和真实数字提炼画面。
- 图位说明与本节原文、章节标题共同决定画面重点；缺少具体说明时仍由原文依据兜底，避免只画抽象标签。
- 没有真实数字的章节只画关系或数量级，不编造坐标、刻度和数据。
- 排除围栏代码、缩进代码和行内图片，避免把示例内容误当作正文事实。
- 表格转换为可读事实，列表续段按同一语义块处理。
- 提示词截断时保护数字与单位，避免百分比、金额等关键信息被截断。
