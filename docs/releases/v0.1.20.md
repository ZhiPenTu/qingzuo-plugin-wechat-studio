# 公众号 AI 工作台 v0.1.20

本次更新为贴图工作流增加可选画幅，默认推荐竖版 `3:4`。插件标识 `official.wechat-studio`，基于轻作插件 API 1.12.0，需要轻作 `v0.8.1`。

## 变更

- 贴图工作流顶部新增「图片比例」：竖版 `3:4`（默认推荐）、方形 `1:1`、横版 `4:3` 和 `16:9`。
- 比例贯通整组方案规划、逐图生图提示词、MCP 尺寸、模型批次参数、方案大纲、会话恢复、发布指纹和 `drafts/` 文章项目。
- 切换比例会把已生成贴图标为需重做，并要求重新生成整组方案；单张生成、保存方案、批量生成、创建草稿和发布都会阻止旧比例结果继续使用。
- 旧贴图会话保持兼容：已有旧图沿用原来的 `1:1`，无图旧方案会提示按新比例重新规划。
- 保存为文章项目时按所选比例生成完整 JPEG 画布，公众号图片消息中的图片保持同一比例。
