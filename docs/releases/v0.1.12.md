# 公众号 AI 工作台 v0.1.12

本次更新重构配图比例与落盘方式，避免封面和正文图片出现主体、文字被裁切或显示不完整的问题，并允许分别设置两类图片的画面比例。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 封面图与正文配图支持独立比例配置，默认均为 `3:4`。
- 可选比例包括 `4:3`、`16:9`、`1:1`、`1.91:1`、`2.35:1`，配置页会显示对应尺寸说明。
- 图片提示词加入安全边距和禁止裁切要求，减少标题、人物主体和关键信息贴边。
- 图片落盘从中心裁切改为完整画面适配，模型请求按能力传递比例或尺寸参数。
- 封面与正文比例不同时自动分组生成并合并结果，不覆盖其他已成功图片。
- MCP 生图支持 `3:4`，文章、行内图片、主题和预览缩略图不再强制使用固定裁切比例。
- 修复分组生成失败时源目录和原始批次 ID 丢失的问题，便于继续排查或重试。
