# 公众号 AI 工作台 v0.1.18

本次更新完善内容审到排版的门禁与 AI 阻断修复流程。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 内容审底部拆分为「处理阻断」和「进入排版」：存在阻断时只能先处理，阻断清零后才能进入排版。
- 「处理阻断」交给 AI 修改正文源文件；AI 输出必须通过本地复检、内容保真和图片结构校验后才写入。
- 修复前从磁盘重新读取正文和发布标题，并保护 AI 请求期间的并发修改；写入失败时安全回滚。
- 发布标题只在自身存在阻断时随修订后的 H1 同步，合法的自定义发布标题不会被覆盖。
- 阶段栏和终审跳转接入同一门禁，避免绕过按钮直接进入排版、配图、终审或发布。
- 正文变化后自动失效旧排版、配图方案、终审和发布产物，避免下游继续使用旧稿。
- 统一审稿与渲染的 Markdown 围栏、引用式图片、协议相对地址和本地图片路径判断，减少假通过与静默丢图。
