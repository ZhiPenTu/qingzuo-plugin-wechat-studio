# 公众号 AI 工作台 v0.1.21

本次更新重构创作工作台与文章项目流程，并加强编辑草稿、发布回执和图片批次的状态保护。插件标识 `official.wechat-studio`，基于轻作插件 API 1.12.0，需要轻作 `v0.8.1`。

## 变更

- 创作工作台收敛为“从想法开始 / 导入或粘贴已有正文 / 继续作品”三类入口，贴图与常用功能独立分区。
- 文章项目由八阶段平铺改为“策划、写作、制作、发布核对”四组导航，并适配移动端。
- 选题方向写入 `pipeline.yaml`，调研阶段确认后同步更新，切换页面或重新打开项目不会丢失。
- 选题卡、调研、正文、内容审和排版增加项目内本地草稿；编辑后自动保存，显式保存后清除，可在重新进入时恢复或丢弃。
- 审稿规则拆分为平台硬限制与账号写作偏好：缺少标题、未闭合代码围栏等仍然阻断，导语、小节数、字数、加粗频次等改为不阻断的提醒。
- 上游内容变化时保留公众号发布回执并标记为过期，不再直接删除 `mediaId`、`publishId` 或未知状态。
- 文章图文草稿与公众号图片消息回执分开识别，禁止在文章发布页查询、重置或覆盖图片消息记录。
- 创建草稿或提交发布后，即使本地回执写入失败，也会保留微信已返回的 `mediaId` / `publishId`，避免重复建稿或重复提交。
- 重新保存早期阶段会清理后续阶段的过期完成状态；标题变化会失效旧审稿、排版、配图与终审产物。
- 图片批次绑定方案签名；生成期间方案变化时旧批次不能重试或写回新图位，生成过程中锁定方案编辑。
- 工作区切换和异步刷新增加 epoch 隔离，降低旧工作区结果覆盖新工作区状态的风险。
