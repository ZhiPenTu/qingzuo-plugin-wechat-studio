# 公众号 AI 工作台 v0.1.4

配图模型来源修复版本，插件标识 `official.wechat-studio`，基于轻作插件 API 1.9.0。

## 修复

- 配图页同时读取官方共享图片模型与兼容服务中的公开生图模型，按来源合并去重。
- 代理模型在下拉框中标注「兼容服务」，创建配图与贴图批次时传递正确的 `source`，避免被当作官方模型。
- 模型列表刷新后自动清理失效的旧选择，避免选中已不存在的模型。
- 空模型提示改为同时说明「共享图片 Key」与「兼容服务生图模型」两种配置方式。
