# 公众号 AI 工作台 v0.1.10

本次更新修复封面与正文配图在排版阶段的联动，并确保重新生成图片后仍保留已选版式。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 已保存的封面会作为正文第一张图进入排版，图注随封面一起保留。
- 生成、单张重新生成、批量生成或导入封面与正文图片后，会同时更新 `article.md` 和 `article.html`。
- 配图方案变化时按最新图位映射回写图片；重复封面、非首位封面和旧封面路径会正确去重或移动到文章顶部。
- 排版阶段选择的主题和配色会写回 `article.yaml`，配图阶段重渲染复用同一套主题、配色、颜色和字号，不会退回默认版式。
- 历史封面文件缺失时降级为可恢复占位符；代码围栏中的图片示例不再被误识别为正文图位。
