# 公众号 AI 工作台 v0.1.14

本次更新支持在配图阶段手动调整封面文案与正文图位说明，并与提示词即时联动更新。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 封面卡片支持直接编辑封面文案/压字，修改后立即重新计算封面提示词。
- 正文配图卡片支持直接编辑图位文案与画面说明，提示词中的图位说明与形态指令同步联动。
- 支持一键重置恢复文章自动提炼的默认文案或图位说明。
- 单张生成、批量生成与仅保存状态均持久化保存自定义文案，重新加载不丢失。
- 重置操作支持完整持久化清理，文章 Markdown 始终保留原始图位说明作为稳定基线，重载后形态与提示词保持一致。
