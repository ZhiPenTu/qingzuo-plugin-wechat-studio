# 公众号 AI 工作台 v0.1.8

修复终审配图占位符误报，并为终审发现的问题补齐处理入口。插件标识 `official.wechat-studio`，基于轻作插件 API 1.11.0，需要轻作 `v0.7.9`。

## 变更

- 已保存封面时，不再把 `![封面：…](placeholder)` 当成未处理配图占位符，终审警告与公众号发布门禁保持一致。
- 终审会同时检查 `article.md` 与 `article.html` 中的真实占位图位；代码块和行内代码里的示例占位符不再误报。
- 终审未通过项新增处理入口：编辑标题、去配图处理、去排版处理、去配置中心。
- 阻断/警告级审稿问题卡片可直接跳转到对应处理阶段，并显示具体占位符文本。
- 配图阶段会列出待补图图位并高亮对应计划卡片，避免带着缺图进入终审。
- 修正封面识别规则：仅图片类型为「封面」或 `cover` 时按封面处理，正文图位描述中出现“封面”不会被误判。
- HTML 中残留占位符时跳转排版阶段重新渲染；封面文件不存在时仍由终审门禁拦截。
